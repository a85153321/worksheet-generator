# 2026-09-17 Reading Comprehension UI Adjustments and Client-Side DOCX Export

## 變更摘要

本輪調整著重於「閱讀理解評量單畫面優化」與「純前端 Word (.docx) 匯出引擎」之實作：

1. **閱讀理解評量單畫面調整**：
   - **完全移除問答題／簡答題**：評量單與模板卡片文案（標籤、特色條列、簡介）100% 僅保留「生字詞義理解選擇題」，徹底排除開放式問答。
   - **短文生成改為使用者明確主動觸發**：切換至或點選「閱讀理解評量單」時嚴禁自動呼叫短文生成，必須由使用者點擊「✨ 生成閱讀短文」按鈕。
   - **生成前提供預估處理範圍與 Quota 提示**：
     - 比照圖片生成提示模式，詳細列出目標年級、已確認生字清單與數量。
     - 清楚標示低中高年級字數限制規範（一至二年級 ≤ 30 字、三年級 ≤ 50 字、四至六年級 ≤ 60 字）。
     - 清楚說明本機 IndexedDB 快取優先機制（快取命中時 0 請求、0 Quota），以及若未命中時僅發送 1 次 Gemini 繁體中文短文請求。
     - Mock 模式醒目提示（未設定 API Key 時使用本機模擬短文，不消耗配額）。
   - **生成中與生成後狀態**：
     - 生成中顯示 loading spinner 與按鈕停用狀態。
     - 生成後正確渲染短文卡片（短文標題、年級、正文字數/上限、涵蓋生字、選擇題題數說明）。
     - 未生成短文時，底部「套用並建立學習單」按鈕保持 disabled，並提示「⚠️ 請先點擊上方「生成閱讀短文」按鈕生成文本後方可建立學習單」。

2. **學習單列印頁面新增「下載 Word 檔 (.docx)」按鈕**：
   - 使用標準 npm 套件 `docx`（^9.x）建立純前端 Word 生成服務 `src/services/docx-builder.ts`。
   - **嚴格遵循 Local-First 與 BYOK 原則**：Word 檔案完全在瀏覽器端記憶體組裝並透過 Blob 下載，完全不經過任何自建後端或第三方雲端服務。
   - **完整支援 6 大學習單模板排版**：
     - `character-practice`（生字田字格練習單）：A4 頁頭、學生資訊欄、部首筆畫讀音標題、田字格（示範紅字格、描字灰字格、1~6 練習格）、造詞參考。
     - `word-practice`（詞語積木擴展單）：核心生字、詞語積木、書寫練習與延伸造詞橫線。
     - `sentence-practice`（句型仿寫應用單）：情境教學例句、兩行仿寫書寫橫線、教師評閱欄。
     - `character-discrimination`（字音字形辨析單）：形近字對照表格（目標字 vs 形近字之部首筆畫與造詞）、多音字破音語境搭配與造句、綜合習寫筆記橫線。
     - `reading-comprehension`（閱讀理解評量單）：短文框（標題與正文）、文意與生詞理解選擇題（題號、題幹、括號 `（　）`、選項 ①②③④ 橫排）。
     - `picture-practice`（看圖識字練習單）：生字標題、看圖寫字、看圖造詞與造句。
   - 觸發方式與現有 PDF 匯出一致，點擊後透過原生 `URL.createObjectURL(blob)` 立即下載檔案，並提供清晰的成功提示。
